Set up a device

Choose what you are setting up and follow the steps. TowerDesk shows exactly what would change before anything is written to a device.

    It must already be in TowerDesk with the MikroTik API, and have SSH switched on.
    It is not in the list
    • Check that it has power and is plugged into the same switch as the MikroTik you chose.
    • A router needs about a minute after it is switched on. Then press Look again.
    • If you know its MAC address (it is printed on the label), you can type it here instead.

    Blank on many models. Newer ones print a unique password on the label.
    Needed if you reach TowerDesk through a VPN.
    The address goes on this port. The default firewall only allows the API on ports inside its LAN bridge.
